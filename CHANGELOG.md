# Changelog

All notable changes to this project are documented here.

Format follows [Keep a Changelog](https://keepachangelog.com/en/1.1.0/);
versioning follows [Semantic Versioning](https://semver.org/).

## [1.1.0] - 2026-11-13

### Added
- **The player's own URL builder, used first** (`engine/alr.js`). The solver
  finds the function containing `.set("alr","yes")`, verifies it behaviourally,
  and lets YouTube's own code solve the cipher:

      builder(url, "s", encodeURIComponent(rawS)).set("n", rawN)

  No helper names, no opcodes, so a rename cannot break it. Verified on build
  `a5c2aafe` (builder `Bs`, serializer `Ue`): solved on the **first probe**.
- The builder is a normal search candidate (tier `0.25`) with its own `n`
  tuple, and it is saved as a replayable recipe (`{kind:'alr'}`), so it survives
  restarts and later renames.
- `node solve.js --discover` reports the builder; `node solve.js --status`
  labels `alr` recipes; `node solve.js --status` / solve output show which
  transform actually won.
- Offline check for the builder in `tools/self-check.js` (synthetic player, no
  YouTube code, no network).
- GitHub Actions workflow running the offline checks on every push and PR.

### Changed
- `cipher.example.txt` is a single placeholder line instead of a `#` comment
  block, so a fresh clone has nothing to delete before pasting.
- README: "Two ways to the same answer" explains the builder and the search,
  and why both are kept.

### Removed
- `mindmap.html` — unused by the app; the flow diagram lives in
  `HOW-IT-WORKS.md`.

### Notes
- Both paths stay: if the marker disappears, `discover()` returns `null` and
  the previous search runs unchanged. The builder failing costs exactly one
  probe.
- 206 from googlevideo remains the only judge, for every path.

## [1.0.0] - 2026-11-12

### Added
- First published release.
- `signatureCipher` parsing for every paste shape (bare value, quoted label,
  indented line, whole `v1/player` response, double-encoded URL).
- Automatic player download with build-hash checking: reuse when current,
  re-download when YouTube ships a new build, retry once on failure.
- Self-learning engine: behavioural discovery, candidate planning, probe
  search, and per-build/per-structure recipe memory.
- 206 as the only success signal — a link is never reported playable without
  proof.
- Local player page (`/`) and `Range` proxy (`/stream`), generated by
  `build-play.js`; live progress page (`/live`).
- `tools/self-check.js` for offline health checks.
